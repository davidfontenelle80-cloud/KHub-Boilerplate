# Aurum Voice V1 Draft

Aurum Voice is a controlled voice-writing app inspired by the useful parts of AI dictation tools without replacing the user's keyboard.

## V1 Scope

- Voice-first composer surface, not a dashboard.
- Manual review before copy, share, or save.
- Local saved notes with search.
- Light and dark mode.
- English and Spanish interface toggle.
- Text sizing controls.
- Tablet, phone, and desktop responsive layout.
- PWA shell with local service worker.

## Later Companion Scope

- Windows and Mac floating mic with active-field insertion.
- Android floating bubble.
- Optional iPad/iPhone companion workflow that avoids keyboard takeover.

## Run

Open `index.html` directly for the draft, or serve the folder from localhost for PWA testing.
